  • MACD (±15 / ±7): a fresh bullish/bearish cross scores more than an already-positive/negative reading.
  • RSI (+15 / +5 / −5 / −10): 50–70 scores best; ≥70 (overbought) and ≤30 (oversold) are capped lower.
